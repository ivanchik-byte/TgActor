# Справочник Команд (COMMANDS.md)

В данном документе собраны основные команды для запуска и базового управления системой TgCast с помощью Docker.

## 1. Подготовка (Первоначальная настройка)

Перед первым запуском необходимо создать файл конфигурации из шаблона и сгенерировать ключ шифрования.

### 1.1. Создание `.env` файла
```bash
cp .env.example .env
```

### 1.2. Генерация ключа шифрования (ENCRYPTION_KEY)
Данный ключ требуется для безопасного хранения сессий Telegram. Скопируйте полученный результат и вставьте его в файл `.env`.
```bash
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

---

## 2. Управление системой (Docker Compose)

### 2.1. Запуск системы (Production Mode)
Команда скачает необходимые образы, соберет проект и запустит все сервисы (БД, Redis, Backend + Frontend) в фоновом режиме. База данных будет автоматически инициализирована.
```bash
docker compose up -d --build
```
> **После успешного запуска панель управления будет доступна по адресу:** `http://localhost:8000`

### 2.2. Просмотр логов
Для мониторинга работы системы, получения отладочной информации и статуса сценариев:
```bash
docker compose logs -f backend
```

### 2.3. Перезапуск системы
Применяется при обновлении исходного кода или изменении переменных в файле `.env`.
```bash
docker compose restart
```

### 2.4. Остановка системы
Корректно завершает работу всех сервисов бота. Данные из базы и сессии не удаляются.
```bash
docker compose down
```
